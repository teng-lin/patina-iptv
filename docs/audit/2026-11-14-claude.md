## What's good

- **Transport security is layered and tested.** Cross-origin requests keep only seven transport headers and a `Referer` cut to its origin (`iptv-net/src/cross_origin.rs:29-60`). The resolver rejects a whole DNS answer if any address is private and hands the vetted addresses to the HTTP client, so there is no check-then-resolve window (`public_resolver.rs:9-26`).
- **The Android player can only load relay URLs.** `RelayGuard.kt` wraps the only HTTP factory Media3 gets and re-checks the address after open.
- **The store service is carefully built.** Two lanes, epoch-scoped work so an old app root cannot write into a new one, a panic discards the connection, and store writes from the UI thread fail an assertion (`runtime/store_service.rs:208-226,311-318,409`).
- **Small files are written atomically off the UI thread.** Temp file, fsync, rename, directory fsync; the latest content wins per path; reads see queued writes (`runtime/file_writer.rs:172-192,278-309`).
- **Guide import is resilient.** Each source has its own 512 MiB and 30 minute budget, retries wait 2, 4 and 8 s and can be cancelled, and permanent errors are not retried (`iptv-import/src/epg.rs:224-266`). The retry tests use a virtual clock.
- **Architecture rules are enforced by tests.** `tests/app/architecture.rs` pins the shell's list of statics, the store boundary and the runtime's ban on NSH. No AGENTS.md violation was found.
- **Releases are fail-closed.** A tag cannot publish unless tests, packaging, signing and the SBOM job passed; every third-party action is pinned by commit SHA; the runtime manifests match the published runtime assets by digest for all three platforms.
- **The docs are accurate.** `docs/architecture.md` describes the tree as it is after the refactors, and the build instructions match CI.

### Low-severity notes

Security:
- **DASH encoding.** The DASH rewriter ignores the declared XML encoding, so an ISO-2022-JP manifest can hide a `SegmentURL` from it (`playback/dash.rs:10-139`). Android's guard blocks it and the shipped desktop runtimes have no DASH demuxer; iOS and system-libmpv builds are exposed.
- **Relay slots.** Any local process can hold all 12 relay connection slots for 15 s at a time without the token and stall playback; the token comparison is not constant-time (`playback.rs:32,284,389,398`).
- **DNS re-pointing.** A user-entered origin is trusted by name, so a provider can later point its DNS into the LAN and get blind GETs on that name and port (`client.rs:136-138`, `redirect.rs:58-70`).
- **Restored backups are trusted as user input.** Private-address sources are accepted, and archives are still plaintext (C37).
- **Plaintext database adoption.** A plaintext database found at startup is adopted and encrypted without the restore-time schema validation (`iptv-store-sqlite/src/encryption.rs:78-88`).
- **Private CAs.** The relay now honours extra root certificates, but nothing in the app fills the list.
- **Android cleartext policy.** Cleartext is allowed for every host, although the player only ever talks to `127.0.0.1`.

Performance and reliability:
- **Combined last channel.** In All-playlists mode the last channel is saved through SQLite, which Android's `onStop` does not wait for (`player.rs:194-204`, `TvActivity.kt:89-95`).
- **WAL growth.** The WAL is never truncated after a large guide publish, so the app keeps about one guide's worth of extra storage.
- **HTTP client per zap.** Every Stalker zap builds a new HTTP client, so no connection is reused (`player.rs:414-416`).
- **Two guide size limits.** A guide sent with gzip transfer encoding is held to a lower limit than the same guide as a `.gz` file.
- **Combined-mode edit.** An organisation edit in All-playlists mode changes a child schedule in place, so group rows can briefly show the wrong group (`data/combined.rs:375-391`).

Other:
- 13 over-long lines are still exempt from the line-length check.
- `iptv-library` lacks `#![forbid(unsafe_code)]`.
- There is no shellcheck, ruff or ktlint step.
- `Cargo.lock` still has three `getrandom` versions.
- The image cache is still insert-ordered.
- iOS has no tests.

## Recommendations (prioritised)

1. **Close the relay gap (N01).** Parse the HLS attribute list instead of searching for a substring, rewrite `URI` quoted or not, and refuse a tag line whose `URI` cannot be parsed. Extend the fuzz oracle to the unquoted form. Then add a second guard for mpv, as `RelayGuard` is for Media3: for example make the relay mpv's HTTP proxy and refuse anything outside the capability. Refuse DASH manifests that declare a non-UTF-8 encoding.
2. **Keep one guide-check timer per source (N02)**, with a cancel token that a refresh, switch, delete or app close cancels.
3. **Take the write connection out of the display path (N03).** Make `refresh_cache` a read, add a blocking reader for workers, and read opening metadata on the reader.
4. **Stabilise the scenario suite, then widen the required checks (N04).** Wait for settled state, not for toasts or in-progress labels; scale waits on CI with one factor. Then require `windows` and `android-check`.
5. **Rehearse the release before tagging v0.1.2 (N05).** Run the publish path against a throwaway draft. Add a written source offer to the v0.1.0 and v0.1.1 notes or supersede them. Turn on immutable releases, secret scanning and push protection.
6. **Finish the runtime refactor (N06 to N08) before starting anything new on top of it.** Move the import loop, combined mode and paging into `runtime/`, delete the events only the shell emits, make `Runtime`'s fields private, move the remaining store-owned value types into `iptv-library`, and turn the boundary test into an allowlist. Split this work into PRs under about 1.5k lines.
7. **Move organisation work off the UI thread (N09)** and make the two custom-group paths linear.
8. **Make localization real or scope it down (N12, N13).** Add a placeholder-capable `tr` with plural categories and locale-aware dates, route the backup, import-failure and organisation text through it, add a test that fails on untranslated literals, and bundle or document CJK fonts. Until then, say in the README that translation is partial.
9. **Process (N15, N19).** Require one approving review, treat "review skipped" as a blocker, file the open items from this report as issues, bring the README and changelog up to date, and commit the audit documents.
10. **Extend provenance (N16).** Add Gradle dependency verification and a second SBOM document for the native runtime and the Android classpath.
